# 开场视频概念 V1 — 纯肌肉展示 + 反转钩子

用途：正式分享开始前播放，1–2 分钟。  
定位：不是解释课程，不讲完整三层方法；只展示“AI 能带我做什么”，制造注意力和信任，然后用反转引出后面的分享内容。

---

## 核心判断

视频 HTML / 视频 base 不应该承担讲课任务。

它只做三件事：

1. 展示肌肉：让观众看到真实能力和产物。
2. 制造反转：这些不是很多工具拼起来的炫技，而是一套系统在工作。
3. 留钩子：后面分享会拆解这套系统怎么搭、怎么复制、怎么避坑。

正式演讲再讲：
n8n / Skills / Agent OS / 顺序学习与逆序搭建 / AI 时代思考拆解 / 资源 takeaway。

---

## 视频主线

一句话：

“我先给大家看一个结果：过去几周，AI 带我搭出了一套可以自动化、写软件、做内容、推进项目、复盘沉淀的个人工作系统。等一下我再拆它是怎么搭出来的。”

---

## 建议时长

最佳：90 秒。  
可接受：75–120 秒。  
不要超过 2 分钟，否则会提前讲完演讲内容。

## 视频不讲什么

不要讲太多：
- n8n 具体设置步骤
- Skill 自进化机制细节
- Agent 框架文件细节
- CER/PTR 项目结构细节
- 顺序学习 / 逆序搭建
- AI 时代产品判断思考

这些留给正式分享。

---

## 视频应该出现的 proof

优先放真实画面 / 文件 / 输出：

1. n8n workflow / pipeline 动效
2. 当前 V4 HTML deck
3. 演讲稿 / 视频稿文件
4. Remotion prototype / video base
5. GitHub commit / repo diff
6. Agent framework：SAM / Andrew / Rex / Lulu / Alex
7. Dashboard / Airtable 状态页（如果能拿到）

---

## 视觉风格

- 更像 trailer，不像课程页。
- 少文字、大焦点、快节奏。
- 每 5–8 秒换一个 proof。
- 画面有“系统启动”的感觉。
- 结尾留悬念，不把方法讲完。

---

## 推荐标题

主标题：
我如何搭了一个个人 AI 工作系统

视频结尾钩子：
先看肌肉，后拆方法。

备选：
AI 不只是聊天窗口。  
当它开始进入工作流，会发生什么？

## 与正式分享的分工

开场视频：
让观众相信“这东西是真的、有结果、值得听”。

正式分享：
讲清楚“它怎么搭、怎么避坑、怎么复制”。
