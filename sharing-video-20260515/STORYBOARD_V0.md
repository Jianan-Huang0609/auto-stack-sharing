# Internal Sharing Video Storyboard v0

Target length: 4–6 minutes
Tone: polished, slightly cinematic, practical not hype
Format: narrated video + animated HTML diagrams + real screenshots + light generated visuals

## 0. Hook — 0:00–0:20

Visual:
- Fast cuts: WeChat instruction → agent task ledger → PLO diagram → n8n workflow → dashboard.

Narration:
"What if AI was not just a chatbot, but an operating system for work? Over the past weeks, I have been building a small multi-agent workflow around product planning, automation, and project delivery. This video explains how it works — and at the end, you will see that this video itself was also made with that system."

## 1. Problem — 0:20–0:55

Visual:
- Messy work board: meetings, CER/PTR tasks, documentation, reporting, development, automation.

Narration:
"The hard part is not asking AI one question. The hard part is keeping context, turning discussions into plans, turning plans into deliverables, and improving the system after each use."

Key message:
AI work needs lifecycle, memory, routing, and feedback.

## 2. Layer One: Skill / PLO — 0:55–2:00

Visual:
- PLO lifecycle diagram, light background.
- Split: B2B Enterprise / B2B Content / ToC / Personal.
- Dual layer view: vertical progress vs horizontal capability packages.

Narration:
"The first layer is skill-based routing. I use PLO — Product Lifecycle Orchestrator — as the entry point for larger tasks. It decides whether the task is enterprise automation, stakeholder content, consumer product, or a personal tool. For CER/PTR, it separates two views: vertical tasks for project execution, and horizontal capability packages for architecture."

Show examples:
- PTR user needs → User/Business Alignment package
- CER transfer → Input/Data + Transfer/Reuse package
- Evals → Verification/QA package

## 3. Layer Two: Multi-Agent OS — 2:00–3:10

Visual:
- SAM in center, Andrew/Rex/Lulu/Alex around it.
- Arrows: memory, task ledger, heartbeat, sessions.

Narration:
"The second layer is multi-agent coordination. SAM is the coordinator. Andrew handles research and learning, Rex handles work and technical execution, Lulu handles content, Alex handles personal support. The key is not that agents exist — it is that they share memory, tasks, and escalation rules."

Show:
- morning ToDo
- task ledger
- memory entries
- agent capability map

## 4. Layer Three: Automation / n8n — 3:10–4:05

Visual:
- n8n workflow screenshot/diagram
- Airtable dashboard
- task digest

Narration:
"The third layer is automation. n8n, Airtable, and dashboards make the system visible and operational. Agents can produce work, but operations need tracking, reminders, evidence links, and feedback loops."

Key message:
Automation turns agent output into operational continuity.

## 5. Feedback Loop: Hermes-style Evolution — 4:05–4:45

Visual:
- Observe → Detect Pattern → Dry-run Patch → Human Confirm → Skill Update.

Narration:
"The final layer is self-improvement. I borrowed the idea of a curator from Hermes: the system observes which skills are useful, what feedback I give, where it fails repeatedly, and only then suggests controlled updates. It does not rewrite itself blindly. It proposes patches, and I approve them."

## 6. Closing Reveal — 4:45–5:20

Visual:
- Timeline of this video being planned by agents.
- Script file, storyboard, generated diagrams, TTS, final video pipeline.

Narration:
"And here is the meta point: this video was not only about the system. It was produced through the system — planned by PLO, structured by agents, assembled from screenshots and generated assets, and reviewed through the same feedback loop."

Final line:
"The future of AI work may not be one perfect agent. It may be a small operating system of specialized agents, skills, memory, workflows, and human judgment."
