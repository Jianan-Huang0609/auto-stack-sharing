# 视频剧本 V4 — 个人 AI 工作系统主线

目标：配合 V4 演讲，先展示个人系统肌肉，再用 CER/PTR 作为轻量 proof。  
建议时长：120 秒左右。  
风格：快速、清楚、真实 proof + Remotion 动效。

---

## Scene 01 — Cold Open：不是工具清单（0:00–0:08）

画面：多个 AI 工具 logo / 聊天窗口快速闪过，被收束成一个系统面板。

字幕：
不是更多 AI 工具，而是一套个人 AI 工作系统。

旁白：
我今天不讲工具清单，先看一个结果。

---

## Scene 02 — Muscle Montage：AI 能带我做什么（0:08–0:25）

画面四连击：
1. n8n pipeline 点亮
2. HTML 分享页面生成
3. Copilot/Codex repo 变更
4. Agent OS 节点启动

字幕：
自动化 / 写软件 / 做内容 / 多 Agent 协作

旁白：
它能帮我跑自动化、写软件、做内容，也能像一个小团队一样持续推进任务。

---

## Scene 03 — n8n 最小闭环（0:25–0:43）

画面：复用 Remotion pipeline。
Trigger → Airtable → Code Decision → Feishu Push → Dashboard。

字幕：
n8n：任务进入 → 判断 → 通知 → 状态更新
Tip：workflow 可以让 AI 直接写 JSON

旁白：
第一层是流程。先做一个最小闭环，不要一开始追求全自动。

---

## Scene 04 — Skills：把经验变成能力（0:43–1:00）

画面：Skill 卡片从文件夹中弹出，并串成 pipeline。
PLO → frontend-slides → ai-video-production → writing-book → airtable-dashboard → reflection。

字幕：
Skills：把重复三次以上的事沉淀下来

旁白：
第二层是能力复用。反复做的事，不要每次重新 prompt，把它写成 Skill。

---

## Scene 05 — Agent OS：从一个 AI 到一个团队（1:00–1:18）

画面：SAM 居中，Andrew / Rex / Lulu / Alex 环绕。Memory、Task Ledger、Heartbeat、Escalation 出现。

字幕：
Agent OS：角色、记忆、任务账本、升级机制

旁白：
第三层是协作。Agent 不只是聊天，而是有角色、有记忆、有任务和升级机制。

---

## Scene 06 — 三层合体（1:18–1:33）

画面：三层结构堆叠。
Agent OS / Skills / n8n + Dashboard。
Human Judgment 在顶部作为 guardrail。

字幕：
Agent 组织协作
Skill 复用能力
n8n 放大流程
Dashboard 建立信任

旁白：
三层合起来，才开始像一个真正的 AI 工作系统。

---

## Scene 07 — 学习路径（1:33–1:45）

画面：两条路径对比。
真实路径：n8n → Skill → Agent OS。
推荐路径：Agent OS → Skill → n8n。

字幕：
顺序学，逆序搭

旁白：
我自己是从 n8n 学起，但如果重新搭，我建议反过来。

---

## Scene 08 — 思考拆解：从问题到资产（1:45–2:02）

画面：三个卡片。
项目反思 → 跨 session 总结 → 知识资产 / 书
做软件 → 产品判断训练
内容分享 → 脚本 / 分镜 / 视频 / 资源包

字幕：
AI 时代，真正重要的是问题拆解能力

旁白：
AI 不只是帮我写东西，它让我把问题拆成系统，把经验变成资产。

---

## Scene 09 — CER/PTR 公司项目轻带（2:02–2:16）

画面：CER/PTR 双层图。
左：项目推进 timeline。
右：能力包 stack。

字幕：
公司项目 proof：复杂流程也可以被拆成可管理结构

旁白：
在 CER/PTR 这样的公司项目里，这套方法也可以把复杂流程拆成任务推进和能力包两层。

---

## Scene 10 — Takeaway / Resources（2:16–2:30）

画面：资源包展开。
Skill 清单、Agent 设置、n8n 最小闭环、Project State。

字幕：
带走一套搭建路径，不只是一个工具列表

旁白：
最后带走的不是工具，而是一套路径：Agent 承载角色，Skill 沉淀能力，n8n 串联流程，人保留判断。
