24 · n8n Concept + Feynman

n8n：流程层

专业概念

Workflow automation：把一连串任务按触发条件、数据流和动作规则自动执行。核心是 Trigger、Data/State、Logic、Action。

费曼解释

n8n 像办公室自动化调度员：看到事件发生，查状态，判断下一步，发消息，更新看板。

n8n 让 AI 输出进入真实管理系统。

25 · n8n Setup + Pitfalls + Tips

n8n 怎么开始？

我的设置Airtable 状态源；n8n 编排；Feishu/WeChat 通知；Dashboard 可视化；GitHub 保存 workflow JSON。
适合做提醒、同步、状态流转、固定规则的判断、系统间连接。
踩坑Credential、命名混乱、失败路径缺失、过早追求全自动。
TipsAI 写 JSON；Code 节点处理复杂判断；每条 workflow 都要有失败路径。
26 · Skills Concept + Feynman

Skills：能力层

专业概念

Skill 不是 prompt 收藏夹，而是可重复执行的做事方法：场景、输入、步骤、输出、验收标准。

费曼解释

Prompt 像一句提醒；Skill 像一份 SOP。新人能照 SOP 做事，Agent 也能照 Skill 稳定产出。

真正的效率，是把做事方法沉淀下来。

27 · Skills Setup + Pitfalls + Tips

Skill 怎么写才有用？

我的设置PLO、frontend-slides、ai-video-production-pack、writing-book、dashboard、reflection。
适合做重复三次以上的任务、高审美交付、结构化分析、项目编排。
踩坑只有原则没有步骤；只有 prompt 没有验收；没有 examples，Agent 会脑补。
Tips写清适用场景、输入、步骤、输出格式、验收标准和反例。
28 · Agent OS Concept + Feynman

Agent OS：协作层

专业概念

Agent OS 不是多开聊天窗口，而是目标、工具、记忆、执行循环、反馈和可视化的组合。

费曼解释

Chatbot 像临时顾问；Agent OS 像一个小团队：有岗位、有任务账本、有交接记录、有复盘机制。

多 Agent 的核心不是多，而是组织方式。

29 · Agent OS Setup + Pitfalls + Tips

Agent 怎么搭才不会乱？

我的设置SAM 主脑；Andrew 学习；Rex 工作；Lulu 内容；Alex 个人。
必备机制SOUL、HEARTBEAT、memory、agent_tasks、PROJECT_STATE、Dashboard。
踩坑角色不清互相覆盖；无任务账本丢上下文；无 dashboard 不可信。
Tips先一主脑一专业 Agent；定义升级规则；长任务必须有状态源和 blocker。

32 · Human Brain Tradeoff

Agent 让学习变简单，但人脑不可省略

当你不知道一个信息时，它对你来说就像不存在。

AI 可以帮你搜索、整合、输出、分析，但不能替你决定哪些问题重要、哪些方向值得投入。
