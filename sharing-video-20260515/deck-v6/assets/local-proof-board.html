# 演讲分享剧本 V6 — 我如何搭了一个个人 AI 工作系统

定位：45min 干货 + 15min Q&A  
受众：跨部门同事，包含业务、软件、自动化方向  
目标：建立认知、展示能力、塑造“懂 AI / 懂系统 / 能落地”的个人品牌，并链接关键同事  
视觉基准：演讲 HTML 使用原始 0506 deck 的米白背景 + 橙色 + 青色基调；视频 HTML 使用橘色调肌肉 trailer

---

## 总体主旨

这场分享不是一个 AI 工具清单。

我真正想回答三个问题：

1. AI 到底能做什么？
2. 在日常管理里，自动化到底能做到什么程度？
3. 一个人怎样用 Agent OS + Skills + n8n，把 AI 变成真实工作系统？

核心句：

不是用 AI 工具，而是设计一套让 AI 正确工作的系统。

### Q3. 你有没有听过 / 玩过 MCP？

- 自己配置过 MCP server / client
- 在 Claude / Cursor / VS Code 里用过
- 听过但没搭过
- 没听过

这里用一句话解释：MCP 像 AI 应用的 USB-C 接口，让 AI 能标准化连接文件、数据库、工具和外部系统。

### Q4. 你有没有自己沉淀过个人 Skill / SOP / Prompt 包？

- 有自己的 Skill / SOP / prompt library
- 有零散 prompt
- 只临时问
- 还没开始

这题是为了引出：真正的效率不是每次问得更聪明，而是把做事方法沉淀下来。

## 过渡讲法

如果你刚才很多题都举手了，今天我希望你能带走更进阶的系统搭建方式：怎么把 n8n、Skill、Agent OS 串起来。

如果你刚才没怎么举手，也没关系。今天至少希望你 get 到一个有趣的实践：AI 不只是聊天窗口，它可以进入工作流，帮你做真实任务。

我的目标不是让大家听完马上搭一套完整系统。

我的目标是：让已经在用 AI 的同事往前走一步，让还没开始的同事下次愿意真实试一次。

## 金句

- 今天不是考大家会不会 AI，而是帮大家看见下一步可以怎么用。
- 举手的人带走进阶实践；没举手的人，下次至少可以举一次手。
- AI 的差距，不只在模型，也在你有没有把方法沉淀下来。

# Grill With Docs (Team Mode)

This skill is based on Matt Pocock's public `mattpocock/skills` methodology, adapted to Jianan's workflow.

## Goal

Relentlessly clarify terms, boundaries, and invariants **and** persist the result into repo docs so that:

- PM / FE / BE / FS share the same vocabulary
- future agents (and humans) stop re-asking the same questions
- architecture decisions don't get silently re-litigated
