# 视频剧本 V3 — 配合“先展现肌肉”的演讲结构

目标：作为演讲开场和中段转场素材，不是完整替代演讲。  
建议短片：90–120 秒。  
叙事顺序：先肌肉展示 → 再三层结构 → 再学习路径 → 最后资源 takeaway。

---

## Scene 01 — Cold Open：AI 能带我做什么（0:00–0:08）

画面：快速闪切四个成果。
1. n8n pipeline 点亮
2. HTML 分享页面生成
3. Copilot/Codex 修改 repo
4. Agent OS 节点图启动

字幕：
先看结果：AI 已经能带我做什么？

旁白：
我先不讲概念，先看结果。

---

## Scene 02 — Muscle 1：n8n 自动化闭环（0:08–0:25）

画面：复用已完成 Remotion pipeline。
Trigger → Airtable → Code Decision → Feishu Push → Dashboard。
数据包流动，最后 Loop Complete。

字幕：
n8n：把 AI 接进真实工作流
Tip：workflow 可以让 AI 直接生成 JSON

旁白：
第一块肌肉，是自动化闭环：读取状态、判断下一步、通知人、更新看板。

---

## Scene 03 — Muscle 2：Copilot + Skills（0:25–0:42）

画面：代码编辑器 / repo 文件树 / Skill 卡片飞入。
流程线：Spec → Plan → Build → Test → Review → Ship。
多个 Skill 卡片串联：PLO、frontend-slides、ai-video-production、airtable-dashboard、writing-book。

字幕：
Copilot + Skills：从写代码到写系统
Tip：十几个 Skill 可以串成体系

旁白：
第二块肌肉，是把一次写代码，变成可复用的软件交付流程。

---

## Scene 04 — Muscle 3：Agent OS / MAE（0:42–0:58）

画面：SAM 居中，Andrew / Rex / Lulu / Alex 环绕。
Memory、Task Ledger、Heartbeat、Escalation 四条轨道浮现。
Dashboard 面板在右侧展开。

字幕：
Agent OS：从一个 AI 到一个团队
MAE + 可视化 = 可管理的多 Agent 执行

旁白：
第三块肌肉，是 Agent 系统：有角色、有记忆、有任务、有升级。

---

## Scene 05 — Three-layer Landing：三层落地方案（0:58–1:16）

画面：三层架构从下到上展开。
Layer 1：n8n / Airtable / Dashboard
Layer 2：Skills / PLO / Model Router
Layer 3：Agent OS / MAE / Multi-AI API

每层旁边出现：概念、优势、设置、踩坑、Tips 五个标签。

字幕：
不是工具清单，是三层工作系统

旁白：
n8n 放大流程，Skill 复用能力，Agent OS 组织协作。

---

## Scene 06 — Learning Path：顺序学习与逆序搭建（1:16–1:30）

画面：两条路径对比。
左：我的真实路径：n8n → Skill → Agent OS。
右：推荐搭建路径：Agent OS → Skill → n8n。

中间出现 warning：不要为了自动化而自动化。

旁白：
我自己是顺序学的，但如果重新搭，我建议反过来。

---

## Scene 07 — Thinking Decomposition：从问题到方案（1:30–1:48）

画面：三个真实思考过程卡片。
1. 项目反思 → 跨 session 总结 → 一本书
2. 做软件 → 训练产品判断
3. 内容分享 → 脚本 / 分镜 / 视频 / Dashboard

字幕：
AI 时代，真正重要的是问题拆解能力

旁白：
AI 不只是帮我写东西，它逼我把问题拆成系统。

---

## Scene 08 — Resources Takeaway（1:48–2:05）

画面：资源清单展开。
左侧：Skill 清单。
右侧：Agent 框架设置。
底部：n8n workflows / Dashboard / Project State。

字幕：
可带走的不是工具，而是搭建路径

旁白：
最后给大家带走三样东西：我的 Skill 清单、Agent 框架设置、三层落地路径。

---

## Scene 09 — Closing（2:05–2:15）

画面：五个词依次出现。
Agent / Skill / Workflow / Dashboard / Human Judgment
最后收束成 AI Operating System。

字幕：
AI 的边界，取决于你如何组织它。

旁白：
AI 的边界，不只取决于模型有多强，也取决于你有没有把它组织成系统。
