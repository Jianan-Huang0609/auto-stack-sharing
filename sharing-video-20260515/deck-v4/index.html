09 · Agent Playbook

Agent 怎么搭，才不会变乱？

最小配置

01一个主脑 + 一个专业 Agent
02Memory + Task Ledger
03Heartbeat + Escalation
04Dashboard 可视化

最容易踩坑

!Agent 太多，协调成本爆炸
!没有边界，任务互相打架
!没有账本，长任务丢失
!heartbeat 只检查不推进
Dashboard 是信任层，不是装饰。
