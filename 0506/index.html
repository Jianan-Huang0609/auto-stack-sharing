01 · Context

The Three Waves of AI Automation

过去半年对自动化的理解，经历了三次范式迭代。每次迭代解决前一个的问题，同时暴露新的瓶颈。

WaveApproachWhat It SolvedNew Problem Exposed
1All-in on LLM chatNatural language as universal interfaceEvery task = new conversation. No automation.
2All-in on n8n / DifyRepeatable workflows, visual programmingComplex logic → spaghetti flowcharts. Visual programming doesn't scale.
3 (now)Layered by determinismRight tool per sub-task typeRequires upfront architecture design. Not plug-and-play.
Core Principle "Which tool is best?" is the wrong question. The right question is "How deterministic is this sub-task?" — and the answer determines the layer.
02 · Framework

The Decision Matrix

三个问题决定任务归属哪一层。不是按工具选，是按确定性选。

QuestionIf YesLayerReason
Execution path is pre-defined?Yesn8n / DifyFixed pipelines don't need runtime decisions
Single-shot high-quality output?YesSkillCrystallized expertise > general reasoning
Requires runtime decision-making?YesAgentThe map is drawn as you walk
Common Mistake

"Multi-step = Agent"

  • n8n is multi-step too
  • Number of steps is irrelevant
  • The distinction: who decides the next step?
Correct Rule

"Runtime decision = Agent"

  • n8n: path drawn at design time
  • Agent: path drawn at execution time
  • Skill: no path — single expert output
03 · Architecture Deep-Dive

5 Patterns from a Production Codebase

来自 local-automation-stack 的实际代码审查。这些模式让多 Agent 系统从「能跑」到「可运维」。

Pattern 1
LENS Gate — Mechanical Validation
LLM says DONE. LENS checks: run_id? log_summary? writeback_ts? All present? → DONE. Missing? → REVIEW retry. 3 failures? → BLOCKED escalation.
REQUIRED = ("run_id", "log_summary", "writeback_ts") if claimed == "DONE" and not evidence_pass: status = "REVIEW" // auto-retry
Pattern 2
State Machine + Lock
LOADED→RUNNING→DONE. Illegal transition? Exception. Idempotency lock with lease expiry prevents cron overlap.
VALID_TRANSITIONS = { "LOADED": {"RUNNING"}, "RUNNING": {"REVIEW","DONE","BLOCKED"}, "BLOCKED": {"RUNNING"}, // human unblock }
Pattern 3
Graceful Degradation Chain
Bridge → LLM API → STUB. Each layer catches its own errors. Caller never knows which path was used.
try: result = bridge.call() except: result = llm_api.call() // never crash, always return something
Pattern 4
Context Trimming (Head+Tail)
Keep message[0] (original goal) + last N messages. Inject trim marker in between. LLM never forgets the mission.
trim(messages, max=40): return [head] + ["...trimmed..."] + tail // Goal always preserved at position 0
Pattern 5
Parent/Child Auto-Aggregation
Parent task = WAITING (not polled). Sub-tasks run in parallel. When all terminal → parent activated. Each sub's log_summary auto-written into parent context.
_check_aggregation(): if all(s in {"DONE","BLOCKED"} for s in siblings): parent: WAITING → LOADED // Sam wakes up parent.messages += [summary of each sub-task]

04 · The Layers

Three Layers, Three Responsibilities

Layer 1
n8n / Dify
The nervous system. Deterministic pipelines: event trigger + fixed path. Flowchart drawn once, runs forever.
  • Scheduled scraping
  • Webhook → process → notify
  • Cross-system state sync
Layer 2
Skill
Muscle memory. Domain expertise crystallized as context. Expert mode on every invocation.
  • Presentation decks
  • Video styling + voice clone
  • High-aesthetic frontend
Layer 3
Agent
The brain. Runtime decision engine. Every step depends on the previous result.
  • Deep content writing
  • Task decomposition
  • Multi-tool orchestration

10 · Getting Started

Implementation Guide

Don't build everything at once. Start here, in this order.

  1. Run one n8n workflow first. Cron trigger → scrape one source → write to Airtable. Build the "pipeline as code" intuition. ~30 min.
  2. Encapsulate one Skill. Your most frequent report or slide deck. Encode best practices into a reusable skill. Feel the value of crystallized domain knowledge.
  3. Introduce an Agent last. Let it orchestrate the first two. The difference between static and dynamic multi-step becomes tangible.
Don't Chase Perfection

Each step delivers standalone value. You don't need all three layers to benefit. Start with one, get value, then add the next.

11 · Takeaways

What to Remember

  1. Three tools, one infrastructure. n8n = nervous system. Skill = muscle memory. Agent = brain. They compose, not compete.
  2. Cognitive leverage. Design once, reuse indefinitely. The architecture compounds.
  3. Capability sedimentation. Experience doesn't dissipate when a project ends. It crystallizes into skills and workflows.
  4. Attention protection. Delegate repetition to the system. Reserve creativity for yourself.
