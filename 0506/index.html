个人 AI 自动化的分层体系

n8n / Dify + Skill + Agent：怎么分工、怎么偷懒、怎么结合。
一个不依赖单一工具、按确定性分层的个人基础设施框架。

Jianan ~45 min v1.0
01 · Context

Why This Matters

过去半年对 AI 自动化的理解，经历了三次迭代。

PhaseApproachProblem
Wave 1All-in on LLM chatNot automated enough. Every task requires a new conversation.
Wave 2All-in on n8n / DifyFlowcharts become spaghetti. Complex logic resists visual programming.
Wave 3 (now)Layered by determinismRight tool for the right job. Each layer owns its strength.
Core Principle

The question is not "which tool is best?" but "how deterministic is this sub-task?" — and the answer determines the layer.

02 · Architecture

The Decision Matrix

Three questions determine which layer owns the work.

QuestionAnswerLayer
Is the execution path pre-defined?Yesn8n / Dify
Is it a single-shot high-quality output?YesSkill
Does it require runtime decisions?YesAgent
Layer 1
n8n / Dify
Deterministic pipelines. Event trigger + fixed path. The flowchart is drawn once and runs forever.
  • Scheduled scraping (cron → YouTube/X)
  • Webhook responses
  • Cross-system sync (Airtable/Feishu/Discord)
  • Notification routing
Layer 2
Skill
Domain expertise crystallized as context. Each invocation triggers expert-mode output.
  • Presentation decks (design + logic + script)
  • Video styling (camera params + style prompt)
  • High-aesthetic deliverables
Layer 3
Agent
Runtime decision engine. Each step depends on the previous result. The map is drawn as you walk.
  • Deep writing (dynamic research)
  • Complex task decomposition
  • Multi-tool orchestration
03 · Layer 1

n8n / Dify: The Pipeline

For everything where the path is known in advance.

n8n is the nervous system. It transmits signals and triggers actions. No thinking required.

Webhook → process → notifyHigh-creativity single outputs
Multi-system state syncMulti-turn reasoning
Scheduled digest generationComplex decision trees (use Agent node instead)

04 · Layer 2

Skill: The Craftsman

Domain expertise encoded as reusable context. Each call produces expert-level output.

A Skill is best-practice knowledge crystallized into a prompt + toolset. The model enters "expert mode" on every invocation.

Skill TypeExampleOutput
Presentation Systemjianan-presentation-systemVisual design + content logic + oral script
Frontend Designopen-design (this page)Production-grade HTML with design system
Codebase to Coursecodebase-to-courseFramework breakdown → teachable curriculum
Video Productionhifly-clone-studioVoice clone + avatar + video pipeline
Key Insight

Skills evolve. A meta-agent periodically reviews all skills, merging redundant ones, splitting bloated ones, and deriving variants. The skill library is a living asset.

05 · Layer 3

Agent: The Decision Engine

Every step is a runtime decision. The map is drawn as you walk.

The difference between n8n and Agent is not "number of steps" — it's who decides the next step.

n8n / DifyAgent
PathPre-definedRuntime-determined
Decision makerHuman (at design time)Model (at execution time)
Best forKnown workflowsOpen-ended exploration
Example"Every morning, scrape 3 sources""Research this topic and decide what to include"

The "multi-step" property alone does not define an agent. Runtime decision-making is the defining characteristic.

09 · Practice

How to Be Lazy: Automation Levels

The essence of automation is shifting human work to the system itself.

LayerLevel 1Level 2Level 3
n8n AI Agent node replaces IF/Switch logic Natural language → LLM generates workflow JSON Runtime logs feed back to LLM for self-optimization
Skill Post-task reflection appends to SKILL.md Meta-agent reviews all skills: merge, split, delete Template derivation (80% shared logic, different tone/scenario)
Agent Use LangGraph / CrewAI / Claude Agent SDK Agent decides which skill to invoke, which n8n workflow to trigger Evaluator agent scores output; auto-retry on fail

Start at Level 1 for each layer. Don't optimize prematurely. Each level has immediate, standalone value.

10 · Getting Started

Implementation Guide

Where to start and in what order.

  1. Run one n8n workflow first. Start simple: a cron trigger that scrapes one information source daily. Build the "pipeline as code" intuition.
  2. Encapsulate one Skill. Pick your most frequent report or deliverable. Encode its best practices into a reusable skill. Experience the value of crystallized domain knowledge.
  3. Introduce an Agent last. Let it orchestrate the first two. Feel the difference between static and dynamic multi-step execution.
Don't Chase Perfection

Each step delivers standalone value. You don't need the full architecture to benefit. Start with one layer, get value, then add the next.

11 · Takeaways

What to Remember

  1. These are not three separate tools. They are a layered infrastructure: n8n is the nervous system, Skill is muscle memory, Agent is the brain.
  2. Cognitive leverage. Design once, reuse indefinitely. The architecture compounds.
  3. Capability sedimentation. Experience doesn't dissipate when a project ends. It crystallizes into skills and workflows.
  4. Attention protection. Delegate repetition to the system. Reserve creativity for yourself.
