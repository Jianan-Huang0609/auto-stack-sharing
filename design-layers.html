个人 AI 自动化的分层体系

n8n × Skill × Agent：按"确定性"分工，不同工具做不同的事
LAYER 03

Agent

Dynamic Multi-Step Executor
大脑 · 做判断、做决策、做调度
本质：图一边跑一边画。每一步根据上一步结果决定下一步做什么。
判据：不是"步骤多"，而是"运行时决策"。
深度文稿写作 复杂任务分解 多工具协同 LangGraph / Claude Agent SDK
偷懒路径
01直接用 Agent 框架，不从零写
02Agent 自主调度 skill / n8n
03Evaluator agent 打分 + 自动重试
LAYER 02

Skill

Domain Knowledge Capsule
肌肉记忆 · 固化专业技能
本质：把某类任务的最佳实践封装成上下文，让模型每次调用都调出"专家模式"。
判据：任务边界清晰、单次可完成、需要领域 know-how。
PPT 生成 视频风格化 海报 / 文案 代码模板
偷懒路径
01任务完成后模型反思并追加到 SKILL.md
02Meta-agent 定期合并 / 拆分 / 删除 skill
03从成熟 skill 派生变体（主题保留 / 口吻变化）
LAYER 01

n8n / Dify

Deterministic Pipeline
神经系统 · 传递信号、触发动作
本质：事件触发 + 固定路径。流程图画完就定了。
判据：路径预先可画、流程不需要"思考"、只需要"可靠"。
定时抓取 (cron) Webhook 响应 跨系统同步 通知分发
偷懒路径
01用 AI Agent 节点替代 IF/Switch 判断
02Vibe 描述 → LLM 生成 workflow JSON
03运行日志回流，让 LLM 自动优化流程

一个简单的判断公式

路径是否预先可画？
是 → n8n / Dify
→
是否是单次高质量输出？
是 → Skill
→
是否需要运行时决策？
是 → Agent

Agent需求澄清对话，确定章节结构
Skill调用 skill 生成视觉 + 内容 + 脚本
n8n自动推送飞书 + 邮件给 reviewer
CASE 02

写内容文稿

多轮决策密集型AGENT 主导
Agent规划大纲 → 过程中动态决策
n8n需要数据时触发资料抓取
Skill结构化写作 + 润色
CASE 03

视频 idea 全流程

三层深度协作闭环三者协作
n8ncron 抓 YouTube/X/小红书 热点
Agent筛选 idea + 生成脚本大纲
Skill风格化 prompt 调 Kling/Runway
n8n分发各平台 + 通知
n8n 是神经系统、Skill 是肌肉记忆、Agent 是大脑
三者不是三个工具，而是一套分层协作的个人自动化操作系统
